# Release 0.3.0 — Professional UX + live agent visibility

**Tag:** `0.3.0` · **Status:** shipped · **Theme:** turn the dark dev console into a calm, light,
clinical product anyone can read — and let you *watch the agent work*.

> Builds on [0.2.0](./0.2.0.md). Presentation-layer overhaul plus two small, safe additions (patient
> identities; a live-assessment stream). The agent, simulator, eval, and the headline result are
> unchanged; the 38 tests stay green.

---

## The product (unchanged)

An AI assistant for a hospital bed-flow coordinator: it watches a simulated hospital, predicts where beds
will run short, explains why, and proposes ranked fixes a human approves before anything changes.
Synthetic data only; no clinical decisions. See [0.1.0](./0.1.0.md) for the full product + architecture.

## What changed (the UI)

A complete front-end redesign, built spec-first (condensed in `spec/0.3.0.md`):

- **Light medical theme** — clinical blue (`#2c7be5`) on calm neutrals, Inter, lucide icons; the dark
  "hacker" look is gone.
- **App shell** — fixed topbar (app name + avatar), a collapsible icon **sidebar** (Dashboard · About ·
  Settings, logout pinned bottom), and **mock auth** (login / route guard / logout).
- **Four screens** — **login**, **dashboard**, **settings** (scenario/seed · model · profile), and an
  **About** page (business flow + architecture, with themed **Mermaid** diagrams).
- **Readable for anyone** — patients shown by **name + UR number**; intervention cards lead with a plain
  action ("Chase pharmacy · Grace Reid") + a one-line explanation; the KPI panel renamed *"Does the
  agent help?"* with plain measures; the **decision timeline** humanised (names, plain words).
- **A working dashboard** — bed-board on its own row; then an **accordion** of columns (ED queue ·
  Discharge queue · Proposed · Flagged · Assessment), one open at a time.
- **Watch the agent live** — pressing **Assess** streams the agent's activity (each tool call + result,
  incl. subagent delegation) into the **Assessment** panel, with a spinner and Re-assess.
- **Floating chat** assistant for plain-language Q&A; **Play** for real-time clock playback; all times via
  **dayjs** (`DD-MM-YYYY HH:mm`).

## Architecture impact (small + safe)

Presentation-only **except**:

- **Patient identities** — deterministic `patientName(id)` / `patientUr(id)` in `src/sim` (safety +
  determinism tests still pass).
- **Live assessment** — `Driver.startAssessment()` runs the agent in the background and
  `planViaOrchestratorLogged()` reports its tool calls by polling the OpenCode session messages. The SDK
  stays isolated to `adapter.ts`; the human-approval gate is untouched.

New deps: `tailwindcss`/`@tailwindcss/postcss` (v4), `lucide-react`, `@fontsource/inter`, `dayjs`,
`mermaid`.

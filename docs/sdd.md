Specify — Write a versioned spec describing what you're building and why: the problem, user stories, acceptance criteria, scope boundaries. No implementation details yet. This lives in a spec/ directory.
Plan — Turn the approved spec into a technical implementation plan: architecture, data model, key decisions and trade-offs.
Break into tasks — Decompose the plan into a discrete, ordered task backlog.
Implement — Only now does Claude Code write code, one task at a time, against the spec.
Test — Verify each piece against the acceptance criteria you defined in step 1.
Maintain — Version-bump the spec as requirements change, keeping spec and code in sync.

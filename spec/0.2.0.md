## Reasoning quality — diagnose & surface all four blocker types (Phase 5) ✅

**Problem it closes:** the agent only proposed fixes for the **two actionable** blockers (pharmacy,
transport). The other two (`allied_health`, `placement`) — which have no v1 one-click fix — were
**invisible** in the plan and UI, so a coordinator couldn't see (or chase) them. That's the completeness
of R5/R6 the core build deferred.

**Delivers:** the agent identifies blockers across **all four** types and surfaces the non-actionable
ones as read-only **`flags`** — rendered as a muted "Flagged — no one-click fix" list under the approval
cards (visible, explained, **no Approve button**).

**Acceptance (G1–G6):**
- **G1** — the plan carries a `flags` list: each not-ready discharge blocked on `allied_health`/`placement`,
  with `patientId`, `wardId`, `blocker`, and a plain-English `reason`.
- **G2** — the orchestrator is prompted to identify all four types and populate `flags` (delegating detail to `@discharge`).
- **G3** — the UI surfaces flags distinctly from actionable interventions, **no Approve/Reject**.
- **G4** — the existing approval cards are unchanged (no regression).
- **G5** — the safety invariant still holds; all existing tests stay green (S13).
- **G6** — live: on a state with `allied_health`/`placement` patients, the real agent surfaces them as flags.

**Key decisions:** the **LLM populates `flags`** (it's the agent's diagnosis, per R5), with the schema
making `flags` **optional** so a sparse reply still parses; a read-only UI sub-section with no buttons;
delegation to `@discharge` is best-effort, not required.

**Evidence:** 38 tests pass (flag parsing + driver exposure; safety green). Live — on a mixed state the
real agent returned **5 actionable interventions + 4 flags** (`placement` p-2/p-11, `allied_health`
p-7/p-14), each with a reason. The previously-invisible stuck patients are now on screen.

**Watch-out (re-confirmed here):** "diagnose" is on the safety denylist, so the prompts use **"identify"** —
the safety test scans agent prompts and would otherwise go red.
